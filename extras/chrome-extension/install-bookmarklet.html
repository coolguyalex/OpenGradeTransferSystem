Aspen Paste Grades: bookmark version

Works without installing an extension. It runs only on the Aspen page you click it on, entirely in your browser.

Install (one time)

  1. Show your bookmarks bar: press Ctrl+Shift+B (Mac: Cmd+Shift+B).
  2. Drag this button up onto the bookmarks bar:

    Aspen Paste
Not working? Run this 10-second test first

Drag this second button to your bookmarks bar too, then click it on any page. If a small box pops up saying it works, bookmarks can run JavaScript on your account and the problem is elsewhere. If nothing happens, your admin is blocking bookmark scripts.

JS test

Use (every time)

  1. Go to Aspen, then Gradebook, then Scores.
  2. Click the Aspen Paste bookmark. The paste panel opens. If you are on the wrong page, a blue message at the bottom right tells you.
  3. Choose the assignment column, paste your Last, First + score rows, review the table, press Fill.
